# MoneyLens

MoneyLens is a personal finance web application built with Python and Flask. It helps users record income and expenses, review financial activity, and manage budgets through a dashboard.

## Features

- User registration and login
- Password hashing
- Session-based access to dashboard pages
- Add, edit, and delete transactions
- View income, expenses, and net savings
- Review recent transactions and spending by category
- View financial analytics over selected time periods
- Create, edit, and delete budgets
- Update profile information and preferences

## Technologies

- Python
- Flask
- MySQL
- MySQL Connector/Python
- HTML, CSS, and JavaScript
- Chart.js

## Requirements

- Python 3
- MySQL Server

## Setup
